# Alisa 的小宇宙

个人绘画展示网页。根目录的 `index.html` 可直接用浏览器打开；此方式仅展示默认内容。

## 本机运行与管理

需要 Node.js。运行 `npm run start`，然后打开 `http://127.0.0.1:8787/`。管理页面是 `http://127.0.0.1:8787/admin.html`；首次打开时创建管理员用户名和至少 12 位的密码。登录后可分别修改首页预览、作品小宇宙、日常卡片的文字和图片。图片限 PNG、JPEG、WebP，每张不超过 3 MB。

内容、账户密码哈希及上传图片保存在本机 `storage/`，不会提交到 Git。页面公开展示由家长管理的联系邮箱。请只上传有权公开的作品和照片，避免包含孩子的学校、住址或固定活动地点。

当前管理服务仅监听本机 `127.0.0.1`。将网站部署到 Vercel 时，静态页面仍可展示，但本机管理服务与本机保存的编辑内容不会自动部署；线上编辑需要另行接入数据库、对象存储及身份验证。

## 验证

`npm test` 运行页面和管理接口测试；`npm run build` 运行 Astro 类型检查，并将当前 HTML 页面及脚本生成到 `dist/`。
